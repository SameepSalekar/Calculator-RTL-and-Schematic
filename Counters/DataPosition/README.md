# Data Position

Data-position counters maintain the current position within
an ordered collection of data.

Within Proteus, these counters are used to manage character
transmission and expression processing.

## LCD Character Index

The LCD character index counter tracks the position of the
current character within the data being transmitted to
the LCD.

## Expression Token Index

The expression token index counter tracks the position of
the current token within a stored mathematical expression,
allowing tokens to be accessed and processed sequentially.
