# FP16 Arithmetic RTL

## Overview

Verilog RTL implementations of IEEE 754 half-precision (FP16) arithmetic operations, including addition, subtraction, multiplication, division, square root, comparison, accumulation, and multiply-accumulate operations.

The modules include combinational and sequential datapaths, control logic, floating-point classification, normalization, rounding, and exception handling.

`FP16ArithmeticEngine.v` integrates the individual arithmetic modules into a unified operation-selectable architecture.
